# Project Atlas

A hands-on Linux, AWS, and DevOps engineering project designed to build real-world cloud infrastructure skills.

## Technologies

- Linux (Ubuntu/WSL)
- Bash Scripting
- AWS CLI
- Amazon S3
- Docker
- Git
- GitHub
- NGINX
- Terraform (In Progress)

## Project Objectives

- Learn Linux administration
- Automate backups using Bash
- Upload backups to Amazon S3
- Monitor system resources
- Deploy web applications with Docker
- Manage infrastructure using Terraform
- Implement CI/CD workflows
- Practice Git version control
